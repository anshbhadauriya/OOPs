######## PRIVATE ############## 

Private methods cannot be overridden

Why?

A private method belongs only to the class where it is declared. The child class cannot access or inherit it.

class Animal {
    private void sound() {
        System.out.println("Animal sound");
    }
}

class Dog extends Animal {

    void sound() {
        System.out.println("Bark");
    }
}

Here, Dog's sound() is not overriding Animal's sound().

They are two completely separate methods.

Why?

Because:

Animal's private sound() → only Animal can access
Dog's sound()            → only Dog's own method

so dono ke apne alg sound method hai 

If you do:

Animal a = new Dog();
a.sound();

 Compile-time error.

Because the reference type is Animal, and Animal.sound() is private.
