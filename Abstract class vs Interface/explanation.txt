so  
Abstract class → common base/family of closely related objects
abstract class Car {
    String brand;

    void start() {
        System.out.println("Car started");
    }

    abstract void accelerate();
}

Then:
class BMW extends Car
class Audi extends Car
class Mercedes extends Car
All of these are Cars and share common properties/behaviour.


Interface → common capability/behaviour
interface Flyable {
    void fly();
}
Different unrelated objects can implement it:
class Bird implements Flyable
class Aeroplane implements Flyable
class Drone implements Flyable
They are not necessarily from the same family, but they all have the same capability: flying.

Best one-line difference 🔥
Abstract class = what things ARE (common family)
 Interface = what things CAN DO (behaviour/capability)
